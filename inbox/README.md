# ============================================================
#  inbox —— 内容投递箱
# ============================================================
#
#  用法（你只需要做第一步）：
#
#  1. 把图片直接丢进 inbox/ 目录（可以放很多张）
#  2. 写一个 inbox/manifest.json 说明这些图和文案怎么用
#  3. 跑：  python tools/ingest.py
#
#  脚本会自动：
#    - 把图片压缩成 webp + jpg 双格式（体积通常降到 1/20）
#    - 存进 img/ 目录
#    - 按 manifest 的说明合并进 js/data.js
#    - 把处理过的文件归档到 inbox/_archive/，不会重复导入
#
# ------------------------------------------------------------
#  manifest.json 格式
# ------------------------------------------------------------
#  {
#    "notes": [
#      {
#        "date": "2026-11-01",
#        "title": "标题",
#        "desc": "正文，随便写",
#        "images": ["IMG:IMG_0001.jpg"]      <- IMG: 前缀表示"本次投递的图片"
#      }
#    ],
#    "works": [
#      {
#        "title": "作品名",
#        "desc": "说明",
#        "status": "wip",
#        "tags": ["Python"],
#        "cover": "IMG:IMG_0002.jpg",
#        "links": [{"label": "源码", "url": "https://..."}]
#      }
#    ],
#    "milestones": [
#      { "date": "2026-11-01", "title": "大事", "desc": "描述", "icon": "🎉" }
#    ],
#    "gallery": [
#      { "src": "IMG:IMG_0003.jpg", "caption": "照片说明" }
#    ]
#  }
#
#  只有 notes / works / milestones / gallery 这四个键是必须的，
#  用不到的键直接删掉。想批量加日常记录就写多条 notes。
#
# ------------------------------------------------------------
#  文件名映射：
#  IMG:IMG_0001.jpg  →  ingest 会把它换成  img/2026-11-01-note-01.jpg
#  也就是"日期-用途-序号"，保证文件名前缀有意义、好认
# ============================================================
